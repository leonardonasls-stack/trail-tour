# Skill: Quadriciclo Grid & Fleet Display
# Context: Showcasing the ATV models available for the customer.
# Stack: Tailwind CSS, HTML.

## Purpose
Create conversion grids presenting the fleet choices. Emphasize mechanical robustness, engine power (CC), and pilot capacity (Single vs. Double).

## Visual Requirements
1. **Specs Grid:** Every card must explicitly state Capacity (1 ou 2 pessoas), Engine Power (ex: 420cc, 570cc), Transmission (Automático / Semiautomático).
2. **Action Item:** Every card needs a direct call-to-action trigger to select that specific vehicle type for the booking flow.
3. Clean modern hover state transitions to zoom into the vehicle preview image.
