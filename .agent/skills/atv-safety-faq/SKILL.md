# Skill: Adaptive Safety & FAQ Injector
# Context: Legal disclaimer and risk mitigation component generation.
# Stack: HTML, Tailwind CSS, Javascript (Accordion behavior).

## Purpose
Build highly readable Accordion blocks answering vital safety constraints. This helps lower the client's drop-off rate by proactively resolving friction points (driving licenses, bad weather policies, safety gear).

## Core Items to Include
- **Habilitação:** Precisa de CNH? (Explain rules for private trails vs. public roads).
- **Equipamentos:** O que está incluso? (Helmet, goggles, mandatory training).
- **Clima:** E se chover? (Emphasize that rain increases the mud factor, making it better, but address cancelation policies for heavy storms).
- **Idade Mínima:** Regras para crianças/carona.
