# Skill: ATV Hero Section Designer
# Context: Frontend development for exclusive quad bike (ATV) tours website.
# Stack: Tailwind CSS, HTML5, Vanilla JS / React.

## Purpose
Generate high-impact, conversion-focused Hero sections for adventure tourism. Focus heavily on an adrenaline-driven visual identity using a dark/rugged palette, contrast accents, and dynamic media grids.

## Guidelines
1. **Color Palette:** Default to asphalt/slate dark backgrounds (`bg-slate-900`, `bg-zinc-950`). Use high-contrast tactical accents like Amber (`text-amber-500`) or Orange (`text-orange-600`) for primary Call-to-Actions (CTAs).
2. **Typography:** Use aggressive, thick sans-serif headers (`font-black`, `tracking-tight`, `uppercase`) to convey power and adventure.
3. **Layout:** Structure a split-screen or full-bleed background layout. Ready for a looping ambient video or high-res background image showing quad bikes in mud/trails.
4. **CTA Strategy:** Always provide a prominent "Reservar Trilha" button linking to WhatsApp or the booking workflow, accompanied by a secondary "Ver Roteiros" outline button.
